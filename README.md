# Вендинг

Мобильное приложение для вендингового бизнеса: продажи, автоматы, группы, транзакции с возвратом.
Данные берутся из API Вендисты через собственный сервер.

- `web/` — само приложение (одна страница, ставится на телефон как приложение)
- `server/` — сервер: вход, запросы к Вендисте, журнал действий (`data/audit.log`)
- `deploy/` — установка (`install.sh`), автообновление (`update.sh`), HTTPS (Caddy)

Установка на сервер с Ubuntu и Docker:

```
curl -fsSL https://raw.githubusercontent.com/ipdaegorov-code/vending/main/deploy/install.sh -o install.sh && bash install.sh
```

## Устройство

- **Аккаунты.** Автоматы, товары, ингредиенты, рецепты, планограммы и загрузки привязаны к аккаунту.
  Доступ к Вендисте (логин и пароль или API-ключ) хранится в настройках аккаунта, в базе, зашифрованно
  (AES-256-GCM, ключ из `SESSION_SECRET`). Меняется в приложении: Настройки → Аккаунт.
- **Пользователи и роли.** У каждого пользователя роль; права проверяются сервером на каждом запросе.
  Сейчас одна роль — «Владелец», видит и может всё. Новые роли добавляются в `ROLES` в `server/server.js`
  из списка прав `PERMS`.
- **Тестовый режим** (по умолчанию): в Вендисте сервер только читает. Данные самого приложения меняются как обычно.
- **Новый аккаунт:** `docker compose exec app node admin.js add-account`, затем `docker compose restart app`.

В `.env` только настройки сервера (`DOMAIN`, `SESSION_SECRET`, режим). База — `data/db.json`, журнал действий — `data/audit.log`.
