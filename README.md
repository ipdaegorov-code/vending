# Вендинг

Мобильное приложение поверх API Телеметрона: продажи, автоматы, группы, сводка за день.

Открыть: https://ipdaegorov-code.github.io/vending/

Приложение работает целиком в браузере: запросы идут напрямую в `api.telemetron.net`.
Ключи и логин вводятся на устройстве и хранятся только в нём; в репозитории нет никаких данных.
